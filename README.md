## 🖥️ WHO ARE WE?

**Forenic Hub** is a growing collection of digital forensics tools, utilities, and resources designed to make forensic workflows more accessible.
We believe powerful tooling should be accessible to everyone from beginners exploring digital forensics to experienced researchers looking for useful utilities.

## 🧰 WHAT WE OFFER
We aim to provide a growing collection of tools across different areas of digital forensics and security research.

| Category | Description |
|---|---|
| 🔍 Digital Forensics | Tools for analysing digital evidence |
| 🧬 File Analysis | Utilities for inspecting and examining files |
| 🌐 Network Analysis | Tools for understanding network activity |
| 🛠️ System Utilities | Useful tools for forensic workflows |
| 📦 Research Tools | Resources for security research and learning |

*More tools and categories coming soon.*

## 🚀 OUR MISSION

We're here to create a central place where people can discover, access, and share useful forensic tooling.

- ⚡ Make forensic tools easier to find.
- 🔓 Encourage open source development.
- 🧠 Support learning and experimentation.
- 🛠️ Develop useful, practical utilities.
- 🤝 Build a community around digital forensics.
